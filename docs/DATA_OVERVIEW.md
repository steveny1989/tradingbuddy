## 📊 数据查询示例

### 查询1：获取中盘股列表
```sql
SELECT code, name, total_cap/100000000 as cap_yi, pe_ttm, pb
FROM market_cap_data
WHERE total_cap >= 5000000000 
  AND total_cap <= 20000000000
ORDER BY total_cap DESC;
```

### 查询2：获取某只股票的历史数据
```python
from core.database import StockDatabase

db = StockDatabase("data/a_share.db")
df = db.get_daily_data("sh.600000", start_date="2024-01-01")
print(df)
```

### 查询3：按行业统计股票数量
```sql
SELECT industry, COUNT(*) as count
FROM industry_data
GROUP BY industry
ORDER BY count DESC;
```

### 查询4：筛选中盘股+特定行业
```sql
SELECT m.code, m.name, m.total_cap/100000000 as cap_yi, i.industry
FROM market_cap_data m
LEFT JOIN industry_data i ON m.code = i.code
WHERE m.total_cap >= 5000000000 
  AND m.total_cap <= 20000000000
  AND i.industry = '软件开发'
ORDER BY m.total_cap DESC;
```
