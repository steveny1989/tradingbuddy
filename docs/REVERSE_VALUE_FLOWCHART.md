## 各过滤器详细逻辑

### 1. 防守过滤器

```
输入：股票代码、名称
  │
  ├─ 检查1：ST股票？
  │    ├─ 是 → ❌ 过滤（风险过高）
  │    └─ 否 → 继续
  │
  ├─ 检查2：资产负债率 > 70%？
  │    ├─ 是 → ❌ 过滤（财务风险）
  │    └─ 否 → 继续
  │
  └─ 检查3：经营现金流连续为负？
       ├─ 是 → ❌ 过滤（经营风险）
       └─ 否 → ✅ 通过
```

### 2. 估值过滤器

```
输入：股票代码
  │
  ├─ 步骤1：获取过去5年PE/PB数据
  │    └─ 数据不足？→ ❌ 过滤
  │
  ├─ 步骤2：计算当前PE/PB
  │
  ├─ 步骤3：计算历史分位数
  │    PE分位 = (历史PE < 当前PE的数量) / 总数量 × 100%
  │    PB分位 = (历史PB < 当前PB的数量) / 总数量 × 100%
  │
  └─ 步骤4：判断是否低估
       ├─ PE分位 < 20% 或 PB分位 < 20% → ✅ 通过
       └─ 否 → ❌ 过滤
```

### 3. 质量过滤器

```
输入：股票代码
  │
  ├─ 步骤1：获取最近4个季度财务数据
  │    └─ 数据不足？→ ❌ 过滤
  │
  ├─ 步骤2：计算每个季度的ROE
  │    ROE = 净利润 / 股东权益 × 100%
  │
  ├─ 步骤3：计算ROE平均值和波动
  │    平均ROE = mean(ROE1, ROE2, ROE3, ROE4)
  │    ROE波动 = std(ROE1, ROE2, ROE3, ROE4)
  │
  └─ 步骤4：判断是否优质
       ├─ 平均ROE > 10% 且 ROE波动 < 5% → ✅ 通过
       └─ 否 → ❌ 过滤
```

### 4. 周期过滤器

```
输入：股票代码
  │
  ├─ 步骤1：获取最近300天数据
  │    └─ 数据不足？→ ❌ 过滤
  │
  ├─ 步骤2：计算250日均线
  │    MA250 = mean(最近250天收盘价)
  │
  ├─ 步骤3：计算乖离率
  │    乖离率 = (当前价 - MA250) / MA250 × 100%
  │
  ├─ 步骤4：检查是否企稳
  │    企稳 = 最近3天最低价不再创新低
  │
  └─ 步骤5：判断是否在周期底部
       ├─ 当前价 < MA250 且 乖离率 < -10% 且 已企稳 → ✅ 通过
       └─ 否 → ❌ 过滤
```

### 5. 逆向过滤器

```
输入：股票代码
  │
  ├─ 步骤1：获取最近10天数据
  │    └─ 数据不足？→ ❌ 过滤
  │
  ├─ 步骤2：检查是否下跌
  │    下跌 = 最新价 < 5天前价格
  │
  ├─ 步骤3：检查是否缩量
  │    缩量 = V1 > V2 > V3（最近3天成交量递减）
  │
  ├─ 步骤4：检查是否企稳
  │    企稳 = 最近2天最低价不再创新低
  │
  └─ 步骤5：判断是否有逆向信号
       ├─ 下跌 且 缩量 且 企稳 → ✅ 通过
       └─ 否 → ❌ 过滤
```

```
用户
  │
  ├─ 场景1：扫描股票池
  │   │

  │       │
```

## 总结

逆向价值策略通过5个过滤器层层筛选，确保：

1. **安全性** - 防守过滤避免永久损失
2. **价值性** - 估值过滤寻找低估股票
3. **质量性** - 质量过滤寻找优质公司
4. **时机性** - 周期过滤把握周期底部
5. **确定性** - 逆向过滤确认技术信号

最终找到的股票具有：
- ✅ 财务健康
- ✅ 估值低迷
- ✅ 盈利稳定
- ✅ 周期底部
- ✅ 技术企稳

这就是霍华德·马克斯投资哲学的程序化实现！
