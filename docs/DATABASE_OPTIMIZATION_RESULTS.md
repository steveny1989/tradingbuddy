## ✅ 实施步骤

### 1. 创建统一表结构
```sql
CREATE TABLE daily_data (
    code TEXT NOT NULL,
    date TEXT NOT NULL,
    open REAL, close REAL, high REAL, low REAL,
    volume REAL, amount REAL,
    amplitude REAL, pct_chg REAL, change REAL, turnover REAL,
    PRIMARY KEY (code, date)
);

CREATE INDEX idx_date_code ON daily_data(date, code);
CREATE INDEX idx_code_date ON daily_data(code, date);
```

### 2. 数据迁移
- **迁移工具**: `tools/optimize_database.py`
- **迁移结果**: 
  - 成功: 5498张表
  - 失败: 100张表（已存在数据，UNIQUE约束）
  - 总记录数: 3,805,412条

### 3. 新增数据库方法
在 `src/data/database.py` 中新增3个高性能方法：

1. **get_market_data_unified(date, codes=None)**
   - 获取全市场或指定股票的某日数据
   - 用途: 日内全市场扫描

2. **get_recent_data_unified(days=10, codes=None)**
   - 获取全市场或指定股票最近N天数据
   - 用途: 策略批量扫描

3. **get_stock_data_batch_unified(codes, start_date, end_date)**
   - 批量获取多只股票历史数据
   - 用途: 回测引擎批量加载
