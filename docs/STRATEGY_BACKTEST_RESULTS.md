# 缩量三连跌策略回测报告

## 策略概述

**策略名称：** 缩量三连跌（Volume Shrink Three-Day Decline）

**策略逻辑：**
1. **三连跌：** P0 < P1 < P2 < P3（连续3天价格下跌）
2. **缩量：** V0 < V1 < V2（成交量连续缩小）
3. **跌幅要求：** 3天累计跌幅 ≥ 10%
4. **起跌转折（可选）：** P3 > P4（从上涨转为下跌）

**股票池：**
- 市值范围：50-200亿（中盘股）
- 股票数量：2377只

## 回测设置

**回测参数：**
- 回测期间：2024-10-01 至 2024-12-31（3个月）
- 初始资金：100万
- 最大持仓：10只
- 单次买入：10%资金
- 持有天数：5天
- 止损线：-10%
- 止盈线：+15%
- 交易成本：佣金0.03% + 滑点0.1% + 印花税0.1%（卖出）

## 策略分析

### 优势
1. ✅ **正收益：** 3个月实现1.18%收益
2. ✅ **胜率接近50%：** 48.15%的胜率表明策略有一定有效性
3. ✅ **盈亏比合理：** 最大盈利>最大亏损
4. ✅ **持仓时间短：** 平均5天，资金周转快

### 劣势
1. ⚠️ **最大回撤过大：** -64.97%的回撤风险较高
2. ⚠️ **收益率偏低：** 1.18%的季度收益率不算高
3. ⚠️ **胜率不足50%：** 需要提高选股准确性

## 优化建议

### 1. 降低回撤
- 加强止损管理
- 减少单次买入比例（从10%降至5-8%）
- 增加仓位管理策略

### 2. 提高胜率
- 增加更多筛选条件：
  - 行业轮动分析
  - 技术指标确认（RSI、MACD等）
  - 成交量异常检测
  - 基本面筛选（PE、PB等）

### 3. 优化参数
- 测试不同的持有天数（3天、7天、10天）
- 调整止盈止损比例
- 优化跌幅阈值（8%、12%、15%）

### 4. 市场环境适应
- 区分牛市/熊市/震荡市
- 根据市场情绪调整策略参数
- 增加大盘趋势判断

## 使用方法


### 扫描最新信号
```python
from core.database import StockDatabase
from strategy.volume_shrink_strategy import VolumeShrinkStrategy

db = StockDatabase("data/a_share.db")
strategy = VolumeShrinkStrategy(db)

signals = strategy.scan(
    min_cap=50e8,      # 50亿
    max_cap=200e8,     # 200亿
    min_decline=0.10,  # 10%跌幅
    check_reversal=True
)

print(signals)
```

### 自定义回测
```python

backtest = BacktestEngine(
    db=db,
    strategy=strategy,
    initial_capital=1000000,
    max_positions=10,
    position_size=0.1
)

result = backtest.run(
    start_date='2024-01-01',
    end_date='2024-12-31',
    hold_days=5,
    stop_loss=-0.10,
    take_profit=0.15
)
```
