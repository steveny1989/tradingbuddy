# 自选股功能测试指南

## 功能概述
已实现基于 localStorage 的自选股管理功能，用户可以从"今日精选"中添加股票到自选股列表。

## 实现的功能

### 1. 添加到自选股
- **位置**: 今日精选卡片右上角
- **按钮**: "加入自选" / "✓ 已加入"
- **功能**: 
  - 点击"加入自选"按钮将股票添加到自选股列表
  - 已添加的股票显示"✓ 已加入"并禁用按钮
  - 防止重复添加
  - 显示成功提示消息

### 2. 自选股列表显示
- **位置**: 自选股监控 - 实时战况区域
- **显示内容**:
  - 股票名称和代码
  - 当前价格和涨跌幅（红涨绿跌）
  - 持仓盈亏百分比
  - 信号状态（买入/卖出/观望）
  - 股票数量统计

### 3. 从自选股移除
- **位置**: 自选股卡片右上角
- **按钮**: "×" 按钮
- **功能**: 
  - 点击移除按钮从自选股列表中删除
  - 显示成功提示消息
  - 自动更新 localStorage

### 4. 数据持久化
- **存储方式**: localStorage
- **存储键**: 'watchlist'
- **数据格式**: JSON 数组
- **包含字段**:
  - code: 股票代码
  - name: 股票名称
  - current_price: 当前价格
  - change_pct: 涨跌幅
  - add_time: 添加时间
  - add_price: 添加时价格
  - signal: 信号状态
  - stop_loss: 止损百分比（默认-10%）
  - take_profit: 止盈百分比（默认+20%）
  - profit_pct: 持仓盈亏

## 测试步骤

### 测试 1: 添加股票到自选
1. 打开浏览器访问 http://localhost:3000/
2. 查看"今日精选 - 神盾雷达"区域
3. 找到任意一只股票卡片
4. 点击卡片右上角的"加入自选"按钮
5. **预期结果**:
   - 按钮变为"✓ 已加入"并禁用
   - 显示成功提示消息
   - 自选股区域显示该股票

### 测试 2: 防止重复添加
1. 对已添加的股票再次点击"加入自选"按钮
2. **预期结果**:
   - 按钮保持"✓ 已加入"状态
   - 按钮不可点击

### 测试 3: 从自选股移除
1. 在"自选股监控 - 实时战况"区域找到已添加的股票
2. 将鼠标悬停在股票卡片上
3. 点击右上角的"×"按钮
4. **预期结果**:
   - 股票从自选股列表中消失
   - 显示"已移除"提示消息
   - 今日精选中该股票的按钮恢复为"加入自选"

### 测试 4: 数据持久化
1. 添加几只股票到自选
2. 刷新浏览器页面（F5）
3. **预期结果**:
   - 自选股列表保持不变
   - 所有添加的股票仍然显示

### 测试 5: 空状态显示
1. 移除所有自选股
2. **预期结果**:
   - 显示"暂无自选股，在今日精选中点击"加入自选"即可添加"
   - 显示股票数量为 0

## 已知限制和未来改进

### 当前限制
1. 自选股价格不会实时更新（需要刷新页面）
2. 止损止盈使用默认值（-10% / +20%）
3. 信号状态固定为 'hold'
4. 没有服务器端存储

### 未来改进方向
1. 实现实时价格更新（WebSocket 或定时轮询）
2. 允许用户自定义止损止盈百分比
3. 根据策略动态计算信号状态
4. 添加服务器端 API 支持多设备同步
5. 添加自选股排序和筛选功能
6. 添加自选股导入/导出功能

## 故障排查

### 问题: 点击"加入自选"没有反应
- 检查浏览器控制台是否有错误
- 检查 localStorage 是否被禁用
- 尝试清除浏览器缓存

### 问题: 刷新后自选股消失
- 检查浏览器是否处于隐私模式
- 检查 localStorage 配额是否已满
- 检查浏览器控制台的错误信息

### 问题: 按钮状态不正确
- 清除 localStorage: `localStorage.removeItem('watchlist')`
- 刷新页面重新测试
