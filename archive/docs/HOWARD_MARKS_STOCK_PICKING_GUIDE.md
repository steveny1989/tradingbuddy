# 基于霍华德·马克斯理论的选股指南

## 核心理念

霍华德·马克斯在《投资最重要的事》中强调：

1. **防守优先** - 避免永久损失比追求高收益更重要
2. **价值为本** - 不是买便宜的，而是买得好的
3. **逆向投资** - 在优质公司被错杀时买入
4. **安全边际** - 价格远低于内在价值时才买入

---

## 选股流程（四步筛选法）

### 第一步：财务健康筛选（防守优先）

**目的：** 避免永久损失，只选财务健康的公司

**标准：**
- ✓ ROE > 10%（盈利能力强）
- ✓ EPS > 0（有盈利）
- ✓ 资产负债率 < 60%（财务稳健）
- ✓ 流动比率 > 1.2（短期偿债能力）
- ✓ 毛利率 > 20%（产品竞争力）

**为什么这些指标重要？**

1. **ROE > 10%**：净资产收益率反映公司为股东创造价值的能力。ROE > 10%说明公司盈利能力强，不是"僵尸企业"。

2. **EPS > 0**：每股收益为正，说明公司在赚钱，不是亏损。这是最基本的要求。

3. **资产负债率 < 60%**：负债率过高意味着财务风险大。< 60%说明公司财务稳健，不会因为债务问题倒闭。

4. **流动比率 > 1.2**：流动资产/流动负债 > 1.2，说明公司短期偿债能力强，不会因为资金链断裂而破产。

5. **毛利率 > 20%**：毛利率高说明产品有竞争力，不是靠价格战生存。

**结果：** 从5000+只股票中筛选出893只财务健康的股票

---

### 第二步：价格大幅下跌筛选（寻找逆向机会）

**目的：** 寻找被市场错杀的优质公司

**标准：**
- 当前价格比历史最高下跌 > 30%
- 不是ST/退市股票

**为什么要找下跌的股票？**

霍华德·马克斯说："最重要的不是顺势而为，而是逆势而为。"

- 优质公司的股价下跌30%+，往往是市场情绪过度悲观
- 这时候买入，安全边际更大
- 但前提是公司基本面健康（第一步已经筛选）

**结果：** 从893只中筛选出383只价格大幅下跌的优质股票

---

### 第三步：估值安全边际筛选

**目的：** 确保价格远低于内在价值

**标准：**
- PB < 3（不追高估值）
- PE < 30（合理估值）
- 股价 < 每股净资产 × 2（安全边际）

**为什么这些估值指标重要？**

1. **PB < 3**：市净率 < 3，说明股价相对净资产不算贵。

2. **PE < 30**：市盈率 < 30，说明估值合理，不是泡沫。

3. **股价 < BVPS × 2**：股价低于每股净资产的2倍，提供了安全边际。即使公司业绩下滑，净资产也能提供支撑。

**结果：** 从383只中筛选出46只具有估值安全边际的股票

---

### 第四步：技术面确认（寻找企稳信号）

**目的：** 确认下跌趋势已经结束，避免"接飞刀"

**标准：**
- 股价在20日均线附近或以上（短期企稳）
- 近5日涨跌幅 > -5%（没有继续暴跌）

**为什么需要技术面确认？**

霍华德·马克斯说："最重要的不是主动寻找机会，而是耐心等待机会上门。"

- 即使基本面好、估值低，也要等股价企稳
- 避免在下跌趋势中买入（"接飞刀"）
- 技术面企稳说明市场情绪开始好转

**结果：** 从46只中筛选出44只技术面确认的股票

## 综合评分公式

**评分 = ROE × 跌幅 / PE**

**为什么用这个公式？**

1. **ROE越高越好**：盈利能力强
2. **跌幅越大越好**：安全边际大
3. **PE越低越好**：估值便宜

这个公式综合考虑了：
- 公司质量（ROE）
- 价格吸引力（跌幅）
- 估值水平（PE）

## 投资建议

### 1. 分散投资
不要把所有资金投入一只股票，建议：
- 选择5-10只股票
- 每只股票占比10-20%

### 2. 分批买入
不要一次性买入，建议：
- 第一次买入30-50%
- 如果继续下跌，再买入30-50%
- 保留20%现金应对意外

### 3. 长期持有
这些股票适合长期持有（1-2年），因为：
- 基本面健康，不会倒闭
- 估值低，安全边际大
- 需要时间让市场认识到价值

### 4. 定期复查
每季度复查一次财务数据：
- 如果ROE持续下降，考虑卖出
- 如果负债率大幅上升，考虑卖出
- 如果股价涨回历史高点附近，考虑获利了结

---

## 风险提示

1. **市场风险**：即使基本面好，股价也可能继续下跌
2. **行业风险**：某些行业可能面临长期衰退
3. **公司风险**：财务数据可能造假或突然恶化
4. **流动性风险**：小盘股可能难以卖出

**建议：**
- 只用闲钱投资
- 做好亏损20-30%的心理准备
- 不要加杠杆

---

## 总结

这套选股方法的核心是：

1. **防守优先**：只选财务健康的公司
2. **逆向投资**：在价格大幅下跌时买入
3. **估值安全**：确保有足够的安全边际
4. **技术确认**：等待企稳信号

这完全符合霍华德·马克斯的投资理念：

> "最重要的不是追求伟大成功，而是避免重大错误。"

通过这套方法，我们：
- 避免了亏损股票（第一步筛选）
- 避免了高估值股票（第三步筛选）
- 避免了接飞刀（第四步筛选）

最终找到的44只股票，都是：
- 财务健康
- 价格回调
- 估值合理
