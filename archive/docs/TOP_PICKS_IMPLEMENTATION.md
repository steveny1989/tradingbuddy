# Top 10 推荐功能实施文档

## 功能概述

在"决策简报"页面添加**今日推荐 Top 10**功能，基于 AI 多维度分析，展示评分最高的前10只股票。

## 设计理念

### 用户价值
- 🎯 **快速决策**：无需逐个搜索，直接看到最优质的股票
- 📊 **数据驱动**：基于诊断引擎的综合评分，客观可靠
- 💡 **一键诊断**：点击任意股票即可查看详细诊断报告

### 视觉设计
- 🏆 **排名展示**：前3名使用金色徽章，突出显示
- 📈 **信心分数**：用颜色和数字直观展示推荐强度
- ✨ **玻璃拟态**：与整体 UI 风格保持一致
- 🎨 **渐变背景**：金色到蓝色的渐变，营造专业感

## 实施内容

### 1. 后端 API ✅

**文件**：`src/web/routes/diagnosis.py`

**新增端点**：`GET /api/diagnosis/top-picks`

```python
@diagnosis_bp.route('/top-picks', methods=['GET'])
def get_top_picks():
    """
    获取今日推荐 Top 10 股票
    
    Returns:
        JSON: {
            "success": true,
            "data": [
                {
                    "code": str,
                    "name": str,
                    "confidence_score": int,
                    "reason": str,
                    "strategy_name": str,
                    "price": float
                },
                ...
            ]
        }
    """
```

**数据来源**：
- 复用"今日精选"的缓存数据
- 按信心分数降序排序
- 返回前10只股票

### 2. 前端组件 ✅

#### A. TopPicks 组件

**文件**：`frontend/src/components/diagnosis/TopPicks.tsx`

**功能**：
- 自动加载 Top 10 数据
- 网格布局展示股票卡片
- 点击卡片跳转到诊断页面
- 加载状态和空状态处理

**样式文件**：`frontend/src/components/diagnosis/TopPicks.css`

**特色设计**：
- 🏆 前3名金色徽章
- 📊 信心分数彩色徽章
- 🎯 策略标签
- 💬 选股理由预览
- ➡️ 悬停动画效果

#### B. 集成到 StockDiagnosis 页面

**文件**：`frontend/src/pages/StockDiagnosis.tsx`

**显示逻辑**：
```typescript
{/* 今日推荐 Top 10 */}
{!report && !isLoading && !error && (
  <TopPicks />
)}
```

**显示时机**：
- 页面初始加载时显示
- 没有诊断报告时显示
- 不在加载状态时显示
- 没有错误时显示

## 交互流程

### 1. 页面加载
```
用户访问决策简报页面
    ↓
自动调用 /api/diagnosis/top-picks
    ↓
显示 Top 10 推荐股票
```

### 2. 点击股票
```
用户点击某只股票
    ↓
跳转到 /diagnosis?code=sh.600519
    ↓
自动触发诊断
    ↓
显示详细诊断报告
```

### 3. 搜索股票
```
用户输入股票代码/名称
    ↓
显示搜索结果
    ↓
点击搜索结果
    ↓
Top 10 隐藏，显示诊断报告
```

## 评分标准

### 信心分数分级

| 分数范围 | 等级 | 颜色 | 标签 |

| 70-100  | 高   | 🟡 金色 | 强烈推荐 |
| 60-69   | 中   | 🔵 蓝色 | 值得关注 |
| 0-59    | 低   | ⚪ 灰色 | 谨慎观察 |
