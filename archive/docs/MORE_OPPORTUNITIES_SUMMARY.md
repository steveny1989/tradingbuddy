## 操作建议

### 1. 分批买入策略

**第一批（40%）：**
- 鲍斯股份、科思股份、招商南油
- 这三只评分最高，风险最低

**第二批（30%）：**
- 口子窖、中信博、正丹股份
- 等待回调5-10%后买入

**第三批（30%）：**
- 根据市场情况，选择其他股票
- 或者加仓前面的股票

### 2. 持有周期

- **短期（3-6个月）**：等待反弹10-20%
- **中期（6-12个月）**：等待反弹30-50%
- **长期（1-2年）**：等待回到历史高点

### 3. 止损策略

- **技术止损**：跌破20日均线，减仓50%
- **基本面止损**：ROE连续2季度下降，清仓
- **总体止损**：单只股票亏损超过20%，清仓

### 4. 获利了结

- **第一目标**：反弹20%，卖出30%
- **第二目标**：反弹40%，卖出30%
- **第三目标**：反弹60%，卖出剩余40%

## 风险提示

1. **市场风险**：大盘下跌，个股难以独善其身
2. **行业风险**：某些行业可能面临长期衰退
3. **公司风险**：业绩不达预期，股价继续下跌
4. **流动性风险**：小盘股可能难以卖出

**建议：**
- 只用闲钱投资
- 分散投资5-10只股票
- 不要加杠杆
- 做好亏损20-30%的心理准备
