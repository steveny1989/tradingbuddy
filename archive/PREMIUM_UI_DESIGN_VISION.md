# 极简选股助手 - 首席级视觉设计方案 🎨

## 设计哲学

**核心理念**: 不是"看数据"，而是"感受市场"
- 用视觉冲击力代替冰冷的数字
- 用动效和光影营造"有人在帮我盯盘"的安全感
- 让用户在3秒内做出决策

---

## 1. 核心视觉：智能"战况"总览（Action Center）

### 1.1 "红绿灯"自选股监控 🚦

**设计概念**: 信号方块矩阵

```
┌─────────────────────────────────────┐
│  自选股监控 - 实时战况              │
├─────────────────────────────────────┤
│                                     │
│  ┌───┐  ┌───┐  ┌───┐  ┌───┐       │
│  │🟢 │  │🟡 │  │🔴 │  │🟢 │       │
│  │浦发│  │平安│  │茅台│  │招商│       │
│  │+2%│  │0% │  │-8%│  │+1%│       │
│  └───┘  └───┘  └───┘  └───┘       │
│   买入    观望   止损!   买入        │
│                                     │
└─────────────────────────────────────┘
```

**视觉特效**:
- 🟢 **买入信号**: 方块边缘绿色呼吸灯（1.5秒周期）
- 🔴 **止损警告**: 方块剧烈闪烁（0.3秒周期）+ 红色光晕扩散
- 🟡 **观望状态**: 静态黄色边框
- **盈亏显示**: 数字颜色跟随中国股市习惯（红涨绿跌）

**交互动效**:
- 鼠标悬停：方块轻微上浮（translateY: -4px）
- 点击：方块放大并展开详情卡片
- 触发预警：方块震动动画（shake animation）

**CSS 实现要点**:
```css
.stock-signal-box {
  position: relative;
  background: rgba(255, 255, 255, 0.05);
  backdrop-filter: blur(10px);
  border-radius: 12px;
  transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}

.stock-signal-box.buy {
  animation: breathe-green 1.5s ease-in-out infinite;
  box-shadow: 0 0 20px rgba(52, 211, 153, 0.5);
}

.stock-signal-box.stop-loss {
  animation: flash-red 0.3s ease-in-out infinite;
  box-shadow: 0 0 30px rgba(239, 68, 68, 0.8);
}

@keyframes breathe-green {
  0%, 100% { box-shadow: 0 0 10px rgba(52, 211, 153, 0.3); }
  50% { box-shadow: 0 0 25px rgba(52, 211, 153, 0.8); }
}

@keyframes flash-red {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.6; }
}
```

### 1.2 "一键同步"能量环 ⚡

**设计概念**: 圆形能量球

```
     平时状态              同步中                完成
    ┌─────┐            ┌─────┐            ┌─────┐
    │  🔵  │    →      │  🌟  │    →      │  🟢  │
    │ 同步 │            │ 88% │            │  ✓  │
    └─────┘            └─────┘            └─────┘
   深蓝静谧           金色旋转            绿色脉冲
```

**视觉特效**:
- **平时**: 深蓝色球体（#1e3a8a），微弱脉冲
- **同步中**: 
  - 球体旋转（360度，2秒周期）
  - 金色光芒扩散（radial gradient）
  - 实时滚动股票简称（ticker）
  - 进度环（stroke-dasharray 动画）
- **完成**: 
  - 绿色脉冲（#10b981）
  - "叮"声音效（可选）
  - 2秒后恢复深蓝色

**实现技术**:
- SVG 圆形进度条
- CSS 3D transform 旋转
- Framer Motion 动画库
- Web Audio API（音效）

## 2. 决策中心：今日"神盾"雷达（Strategy Radar）

### 2.1 卡片流设计（Card Carousel）

**设计概念**: 横向滚动的精选股票卡片

```
┌──────────────────────────────────────────────────┐
│  今日精选 - 神盾雷达                              │
├──────────────────────────────────────────────────┤
│                                                  │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐         │
│  │ 🎯 72分 │  │ 🎯 68分 │  │ 🎯 64分 │  →      │
│  │         │  │         │  │         │         │
│  │ 安联锐视 │  │ 金新农  │  │ 星帅尔  │         │
│  │ ¥88.00  │  │ ¥6.08   │  │ ¥14.10  │         │
│  │         │  │         │  │         │         │
│  │ 放量突破 │  │ 金叉启动 │  │ 趋势向上 │         │
│  │         │  │         │  │         │         │
│  │ [K线图] │  │ [K线图] │  │ [K线图] │         │
│  └─────────┘  └─────────┘  └─────────┘         │
│                                                  │
└──────────────────────────────────────────────────┘
```

**卡片设计要点**:
- **大标签**: "放量突破"、"回踩支撑"、"金叉启动"
- **信心指数**: 大号数字 + 🎯 图标
- **K线缩略图**: 半透明背景，鼠标悬停时高亮
- **大白话理由**: 
  - ✅ "这只票最近主力在悄悄进货，像是在憋大招"
  - ✅ "短期均线上穿长期均线，趋势可能转强"
  - ❌ 不要 "MA5上穿MA20，MACD金叉"

**视觉层次**:
1. **第一眼**: 信心指数（72分）
2. **第二眼**: 股票名称 + 价格
3. **第三眼**: 策略标签
4. **背景**: K线图缩略图（透明度 20%）

**交互动效**:
- 横向滚动：平滑滚动（smooth scroll）
- 卡片悬停：轻微放大（scale: 1.05）+ 阴影加深
- 点击卡片：翻转动画展开详情

### 2.2 大白话理由库

**策略 → 大白话映射**:

| 技术策略 | 大白话理由 |
|---------|-----------|
| 低位放量突破 | "连续下跌后突然放量，可能有主力资金进场" |
| 多头排列启动 | "短期均线上穿长期均线，趋势可能转强" |
| 回踩支撑买入 | "价格回调到重要支撑位后企稳，可能反弹" |
| 成交量放大 | "成交量突然放大X倍，可能有资金进场" |
| 突破前高 | "股价突破前期高点，可能继续上涨" |

## 4. 首席级视觉方案

### 4.1 背景纹理：数据流颗粒

**设计概念**: 深航海蓝 + 动态颗粒

```css
body {
  background: #0d1117;
  background-image: 
    radial-gradient(circle at 20% 50%, rgba(59, 130, 246, 0.1) 0%, transparent 50%),
    radial-gradient(circle at 80% 80%, rgba(16, 185, 129, 0.1) 0%, transparent 50%);
  position: relative;
}

/* 数据流颗粒动画 */
.data-particles {
  position: fixed;
  width: 100%;
  height: 100%;
  pointer-events: none;
}

.particle {
  position: absolute;
  width: 2px;
  height: 2px;
  background: rgba(59, 130, 246, 0.3);
  border-radius: 50%;
  animation: float 10s infinite ease-in-out;
}

@keyframes float {
  0%, 100% { transform: translateY(0) translateX(0); opacity: 0; }
  10% { opacity: 1; }
  90% { opacity: 1; }
  100% { transform: translateY(-100vh) translateX(50px); opacity: 0; }
}
```

**效果**: 
- 微小的蓝色光点从底部缓慢上升
- 营造"大数据正在后台飞速计算"的科技感
- 不干扰主要内容

### 4.2 玻璃拟态（Glassmorphism）

**设计规范**:

```css
.glass-card {
  background: rgba(255, 255, 255, 0.05);
  backdrop-filter: blur(10px) saturate(180%);
  border: 1px solid rgba(255, 255, 255, 0.1);
  border-radius: 16px;
  box-shadow: 
    0 8px 32px 0 rgba(31, 38, 135, 0.37),
    inset 0 1px 0 0 rgba(255, 255, 255, 0.1);
}

/* 悬停效果 */
.glass-card:hover {
  background: rgba(255, 255, 255, 0.08);
  border-color: rgba(255, 255, 255, 0.2);
  transform: translateY(-2px);
  box-shadow: 
    0 12px 40px 0 rgba(31, 38, 135, 0.45),
    inset 0 1px 0 0 rgba(255, 255, 255, 0.15);
}
```

**应用场景**:
- 所有卡片模块
- 弹出层
- 导航栏
- 按钮

**视觉连续性**:
- 当切换页面时，背景的金色自选股光芒会隐约透出来
- 保证视觉的连续性和沉浸感

### 4.3 数字动态加载

**实现方案**:

```typescript
import { useCountUp } from 'react-countup';

function AnimatedNumber({ value, suffix = '%' }) {
  const { countUp } = useCountUp({
    start: 0,
    end: value,
    duration: 1.5,
    decimals: 2,
    suffix: suffix,
    useEasing: true,
    easingFn: (t, b, c, d) => {
      // easeOutExpo
      return c * (-Math.pow(2, -10 * t / d) + 1) + b;
    }
  });
  
  return <span className="animated-number">{countUp}</span>;
}
```

**应用场景**:
- 收益率百分比
- 信心指数
- 胜率
- 盈亏金额

**视觉效果**:
- 数字从 0 快速翻转到目标值
- 像老式里程表一样
- 增加界面的"爽感"

## 6. 动效库推荐

### 6.1 核心动画库

1. **Framer Motion** (React)
   - 用于: 页面过渡、卡片动画、手势交互
   - 优势: 声明式API、性能优秀

2. **GSAP** (GreenSock)
   - 用于: 复杂动画序列、SVG动画
   - 优势: 强大、灵活、兼容性好

3. **Lottie** (Airbnb)
   - 用于: 复杂矢量动画（如能量球）
   - 优势: 设计师友好、文件小

### 6.2 特效库

1. **Particles.js**
   - 用于: 背景数据流颗粒
   
2. **CountUp.js**
   - 用于: 数字翻转动画

3. **React Spring**
   - 用于: 物理动画（弹簧效果）

## 8. 性能优化

### 8.1 动画性能

```css
/* 使用 GPU 加速 */
.animated-element {
  will-change: transform, opacity;
  transform: translateZ(0);
}

/* 避免重排 */
.animated-element {
  /* ✅ 使用 transform */
  transform: translateY(-4px);
  
  /* ❌ 避免使用 top/left */
  /* top: -4px; */
}
```

### 8.2 懒加载

- K线图: 进入视口时才渲染
- 数据流颗粒: 使用 requestAnimationFrame
- 图片: 使用 lazy loading
