# 快速开始：如何使用"优质陨落之星"选股工具

## 一、运行选股程序

```bash
python3 find_quality_fallen_stars.py
```

程序会自动：
1. 筛选财务健康的股票（ROE > 10%，负债率 < 60%等）
2. 找出价格大幅下跌的股票（跌幅 > 30%）
3. 筛选估值合理的股票（PE < 30，PB < 3）
4. 确认技术面企稳的股票

## 五、投资建议

### 1. 分散投资
选择5-8只股票，每只占比10-20%

### 2. 分批买入
- 第一次买入40%
- 如果下跌5-10%，再买入30%
- 保留30%现金

### 3. 持有周期
建议持有1-2年，等待价值回归

### 4. 止损策略
- 如果ROE连续2个季度下降，考虑卖出
- 如果负债率突然上升超过70%，立即卖出
- 如果股价跌破净资产，重新评估

## 六、调整参数

如果想要更多/更少的股票，可以修改 `find_quality_fallen_stars.py` 中的参数：

```python
# 第一步：财务健康筛选
roe > 10          # 改为 8 可以放宽标准
eps > 0           # 必须盈利
debt_to_asset_ratio < 60  # 改为 70 可以放宽标准

# 第二步：价格下跌筛选
min_drop_pct = 30  # 改为 20 可以找到更多股票

# 第三步：估值筛选
pb < 3            # 改为 5 可以放宽标准
pe < 30           # 改为 50 可以放宽标准
```

## 七、常见问题

### Q1: 为什么有些股票跌幅很大但没有入选？
A: 因为它们不满足财务健康标准（ROE < 10%，或负债率 > 60%，或亏损）

### Q2: 这些股票会继续下跌吗？
A: 可能会。但因为基本面健康、估值低，长期看有上涨潜力。

### Q3: 什么时候卖出？
A: 
- 股价涨回历史高点附近（获利了结）
- ROE连续下降（基本面恶化）
- 负债率大幅上升（财务风险）

### Q4: 可以全仓买入吗？
A: 不建议。即使是优质股票，也要分散投资，控制风险。
