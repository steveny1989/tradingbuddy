# 盘后复盘系统 - 产品定义文档

## 产品愿景

**"让你的投资不再有夜路"**

TradingBuddy 盘后复盘系统是一个**5分钟极简复盘工具**，让普通投资者无需理解复杂的技术指标，就能快速完成每日复盘并做出投资决策。

---

## 核心价值主张

### 对用户的价值

1. **节省时间**: 从2小时复盘缩短到5分钟
2. **降低门槛**: 不需要懂技术指标，看懂红绿灯就够了
3. **提高胜率**: 基于历史数据验证的推荐，胜率 > 50%
4. **减少亏损**: 自动体检持仓，及时止损

### 对产品的价值

1. **差异化竞争**: 市场上没有如此简单的复盘工具
2. **用户粘性**: 每天晚上必用，形成习惯
3. **数据积累**: 收集用户决策数据，持续优化算法
4. **商业化潜力**: 高级功能可以付费订阅

## 三大核心模块

### 模块一：市场"体温计" 🌡️

**目标**: 3秒内让用户知道明天该不该操作

**输入数据**:
- 涨停股票数量
- 跌停股票数量
- 连板高度（最高连续涨停天数）
- 两市成交额

**输出结果**:
```
🔴 情绪火热（大胆操作）
   今日涨停120只，连板高度7板，成交额1.2万亿
   建议：积极参与，关注强势板块

🔵 情绪冰点（等待机会）
   今日跌停150只，成交额仅4500亿
   建议：观望为主，等待企稳信号

⚪ 情绪平淡（按兵不动）
   市场波动不大，成交额8000亿
   建议：持股待涨，不追高不杀跌
```

**判断逻辑**:
```python
if 涨停数 > 100 and 连板高度 > 5 and 成交额 > 10000亿:
    return "情绪火热"
elif 跌停数 > 100 or 成交额 < 5000亿:
    return "情绪冰点"
else:
    return "情绪平淡"
```

```
🔴 中路股份 (600818)
   现价: ¥9.59  涨跌: -5.8%  偏离20日线: -8.3%
   破位下跌，触发系统止损阈值，建议立即止损
```

**判断逻辑**:
```python
# 使用现有策略
ma_signal = ma_crossover.check(stock_code)
volume_signal = volume_shrink.check(stock_code)

    return "🟡 黄灯（警示）"
elif ma_signal == "下跌" or 跌幅 > 5%:
    return "🔴 红灯（危险）"
```

**筛选逻辑**:

```python
# 1. 运行回测引擎，计算所有板块/个股的历史表现
```

## 自动化流程

### 每日执行流程

```
16:00 - 数据同步开始
  ↓
16:05 - 数据同步完成，触发复盘生成
  ↓
16:10 - 市场情绪计算完成
  ↓
16:15 - 持仓健康检查完成（如果用户有持仓）
  ↓
16:20 - 回测引擎开始运行
  ↓
19:30 - 回测引擎完成，明日锦囊生成
  ↓
19:45 - 报告生成完成，写入缓存
  ↓
20:00 - 用户打开App，立即看到报告
```

### 失败处理

```
IF 数据同步失败:
    重试3次
    IF 仍然失败:
        发送告警
        使用昨日数据生成报告（标注"数据异常"）

IF 回测引擎超时:
    使用简化版算法
    降低推荐数量（从3个降到1个）

IF 报告生成失败:
    发送告警
    显示"系统维护中"页面
```

## 数据质量保证

### 过滤规则

```python
def filter_junk_stocks(stocks):
    """过滤垃圾股"""
    filtered = []
    
    for stock in stocks:
        # 1. 过滤ST股票
        if 'ST' in stock.name or '退' in stock.name:
            continue
        
        # 2. 过滤流动性不足
        if stock.daily_volume < 10_000_000:  # 日成交额 < 1000万
            continue
        
        # 3. 过滤异常波动
        if abs(stock.pct_change) > 15 and not stock.has_fundamental_support:
            continue
        
        # 4. 过滤数据异常
        if not data_validator.validate(stock):
            continue
        
        filtered.append(stock)
    
    return filtered
```

### 历史胜率验证

```python
def validate_recommendation(recommendation):
    """验证推荐的历史胜率"""
    
    # 计算过去30天、90天、1年的胜率
    win_rate_30d = calculate_win_rate(recommendation, days=30)
    win_rate_90d = calculate_win_rate(recommendation, days=90)
    win_rate_1y = calculate_win_rate(recommendation, days=365)
    
    # 如果任何一个胜率 < 50%，不推荐
    if min(win_rate_30d, win_rate_90d, win_rate_1y) < 0.5:
        return False
    
    # 如果CAGR < 10%，不推荐
    if recommendation.cagr < 0.1:
        return False
    
    return True
```

## 风险与挑战

### 技术风险

1. **回测引擎性能**: 可能无法在3小时内完成所有回测
   - **解决方案**: 使用增量回测，只计算变化的部分

2. **数据质量**: 市场数据可能不准确或延迟
   - **解决方案**: 多数据源验证，异常数据标记

3. **并发压力**: 晚上8-11点可能有大量用户同时访问
   - **解决方案**: 提前生成报告，使用缓存

### 产品风险

1. **用户不理解**: 用户可能不理解红绿灯的含义
   - **解决方案**: 新手引导，视频教程

2. **推荐失败**: 推荐的股票可能亏损，用户流失
   - **解决方案**: 明确标注"历史胜率"，设置免责声明

3. **竞争压力**: 其他产品可能模仿
   - **解决方案**: 持续优化算法，建立数据壁垒
